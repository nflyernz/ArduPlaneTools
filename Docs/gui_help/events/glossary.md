# Events glossary

- **Timeline event** — A timestamped record retained by the Event extractor.
- **MSG** — Firmware text written to the DataFlash log.
- **MODE** — A logged flight-mode record, presented using the known mode name.
- **LAND stage** — A landing-controller stage value; only transitions are shown.
- **Flight window** — The selected detected-flight interval that bounds event extraction.
- **Log-relative time** — Time derived from DataFlash `TimeUS`, rather than wall-clock time.
- **Event detail** — Source text or fields associated with the event, such as LAND height and slope diagnostics.
