# AUTOTUNE glossary

- **Session** — A bounded AUTOTUNE interval established by authoritative mode and tuning evidence.
- **Configured axes** — Axes enabled by configuration at session start.
- **Selected axes** — Axes selected for the observed tune.
- **Active axis** — An axis with retained tuning activity records.
- **ATRP** — ArduPlane AUTOTUNE rate-process log records used for axis activity and runtime gains.
- **Demand period** — A bounded interval of positive or negative tuning demand.
- **Action baseline / transition** — Logged AUTOTUNE action state and observed changes.
- **Runtime gains** — Gain values observed during execution; they need not be persisted parameters.
- **Completion milestone** — Firmware evidence that an axis reached a tune milestone.
- **Save requested / restore inferred** — Evidence classifications for exit persistence behavior.
- **Normal stop not observed** — The session ended without the detector's authoritative normal-stop evidence.
