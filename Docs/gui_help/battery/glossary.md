# Battery glossary

- **Battery instance** — One configured/logged battery-monitor source.
- **Pack ID** — A user-managed identity for a physical battery pack.
- **Voltage sag** — Pre-load voltage minus the minimum voltage during a bounded load event.
- **Voltage recovery** — The reported rise from minimum loaded voltage to the later recovery sample.
- **Sag per ampere** — Voltage sag divided by event current when supported.
- **mAh / Wh** — Logged capacity and energy consumption measures.
- **Consumption rate** — Consumed mAh divided by analysed flight duration.
- **Bounded load event** — A detected, time-bounded high-load context with associated electrical samples.
- **LOW / CRITICAL margin** — Minimum loaded-voltage difference from configured battery thresholds.
