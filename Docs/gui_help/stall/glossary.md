# Stall Analysis glossary

- **Probable demand-opposed attitude departure** — Logged attitude stopped following continuing nose-up FBWA demand in the required evidence sequence.
- **No demonstrated departure** — A usable attempt did not demonstrate that required signature; it does not establish a safe speed.
- **Ambiguous** — A real manoeuvre lacked complete or consistent decisive evidence.
- **Rejected candidate** — A movement lacked sufficient support as an analysable attempt.
- **Pre-fall pitch-peak airspeed** — Raw ARSP sample associated with the attitude peak before the opposed fall.
- **Minimum usable airspeed** — Lowest suitable attempt sample, which may occur in another phase.
- **Effective airspeed ratio** — Runtime calibration ratio supported for the relevant raw sample.
- **Clean-idle cohort** — Same-flight compatible probable events with idle-commanded throttle and approximately level context.
- **Recovery-control action** — Observed pilot-demand, target, or commanded-power change; it is not proof of completed recovery.
- **FBWA** — Fly By Wire A mode, required here to relate pilot demand, target, output, and response.
