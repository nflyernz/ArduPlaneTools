# Landing glossary

- **Flight window** — One detected armed-flight interval used to scope analysis.
- **Landing window** — A bounded interval in which the landing detector found relevant landing-controller evidence.
- **Landing attempt** — One extracted attempt within a landing window.
- **Approach** — The portion preceding the configured preflare and flare evidence.
- **Preflare** — The logged preflare transition and its associated measurements.
- **Flare** — The logged flare-timing transition; it is not proof of physical touchdown.
- **Glide slope** — The calculated approach-path angle reported by the processor.
- **Sink rate** — Logged vertical descent rate associated with an event.
- **GPS stop** — The detected low-groundspeed endpoint used for rollout completion evidence.
- **Rangefinder in range** — A usable logged rangefinder observation within the configured evidence range.
