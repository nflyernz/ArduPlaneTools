# Pack Performance glossary

- **Battery session** — One source BIN used to group retained takeoff observations.
- **First takeoff** — Earliest retained supported AUTO takeoff observation in a source session.
- **All AUTO takeoffs** — Every retained supported AUTO takeoff observation owned by the pack.
- **Capacity used** — Logged consumed capacity before the bounded event, in mAh.
- **Pre-load voltage** — Valid voltage sample selected before the bounded load.
- **Minimum loaded voltage** — Lowest valid voltage selected during the event.
- **Peak / average current** — Maximum and mean logged current within the bounded event.
- **Owned history** — Observations whose source fingerprint is currently assigned to the selected Pack ID.
