# Pack Performance

Pack Performance compares battery observations saved by the **Battery Pack Management** module. It lets you review the history of each physical battery across multiple flight logs. No BIN selection is required.

Open the tab to load your saved Pack IDs and battery history. Choose a Pack ID and select **View report**. Use **Refresh** after making changes in Battery Pack Management. Your selection is retained if that Pack ID still exists.

The report provides two views: the first recorded AUTO takeoff from each battery session, and all recorded AUTO takeoff observations. Results include flight date, source log, flight number, capacity used before takeoff, average and peak current, voltage under load, voltage sag and recovery.

Only observations from BIN logs currently assigned to the selected Pack ID are included. Changing a log's Pack ID changes which battery report includes its history without modifying the BIN file.

Pack Performance is read-only. Use **Battery Pack Management** to manage Pack IDs and record additional battery history.
